# AceRP-MDT
MDT Script for RSG Framework on RedM using ox_lib.

**For support and suggestions join the discord: https://discord.gg/NBcXdtD2XZ**

**Features:**
- Automatically syncs all players profiles
- Search Profiles (Can search with firstname, lastname, or their CID)
- Search Reports
- Create Reports
- Create Warrants
- Edit and Delete Reports
- Supervisor Restricted Abilities (Delete and Edit any Report)

**Dependencies:**
- [RSG Framework](https://github.com/Rexshack-RedM)
- [ox_lib](https://github.com/Rexshack-RedM/ox_lib)
- [ox_target](https://github.com/Rexshack-RedM/ox_target)

**Usage:**
- /mdt (Default command, you can change it in the config)
- ox_target interaction at any law station (Can change locations in config)
